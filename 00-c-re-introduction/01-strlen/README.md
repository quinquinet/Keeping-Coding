# M00 - Exercise 01 - Strlen - ⭐

## Description

This exercise is a simple implementation of the `strlen` function in C.

## Instructions

Allowed functions: *None*

Create a function named `ft_strlen` in a file named `ft_strlen.c` that takes a string as input and returns its length as an integer. The function should be declared as follows:
```c
int ft_strlen(char *str);
```

File must compile using `gcc -Wall -Wextra -Werror` to pass the validation.

### Solution

The given solution may contain mistakes, please report any issues you find. You can find the solution in the `solution` folder.
