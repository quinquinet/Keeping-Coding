# M00 - Exercise 04 - Split - ⭐⭐⭐

## Description

This exercise ask a implementation of the `split` function in C.

## Instructions

Allowed functions: *`malloc`*
Create a function named `ft_split` in a file named `ft_split.c` that takes a string and a character as input and returns an array of strings, which are the substrings of the input string split by the given character. The function should be declared as follows:
```c
char **ft_split(char *str, char delim);
```
The output array should be terminated by a NULL pointer.

File must compile using `gcc -Wall -Wextra -Werror` to pass the validation.
