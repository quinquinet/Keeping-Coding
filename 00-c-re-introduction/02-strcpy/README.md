# M00 - Exercise 02 - Strcpy - ⭐

## Description

This exercise is a simple implementation of the `strcpy` function in C.

## Instructions

Allowed functions: *None*
Create a function named `ft_strcpy` in a file named `ft_strcpy.c` that takes two strings as input and copies the second string into the first. The function should be declared as follows:
```c
char *ft_strcpy(char *dest, char *src);
```
