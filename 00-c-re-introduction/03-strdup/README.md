# M00 - Exercise 03 - Strdup - ⭐⭐

## Description

This exercise is a simple implementation of the `strdup` function in C.

## Instructions

Allowed functions: *`malloc`*
Create a function named `ft_strdup` in a file named `ft_strdup.c` that takes a string as input and returns a new string which is a duplicate of the input string. The function should be declared as follows:
```c
char *ft_strdup(char *src);
```

File must compile using `gcc -Wall -Wextra -Werror` to pass the validation.
