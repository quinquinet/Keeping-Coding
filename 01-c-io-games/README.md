# Module 01 - C Input/Output Games - ⭐

## Description

This module is meant to introduce you to the basics of the C standard Input/Output (meaning in the console using `stdio.h`). All the exercises in this module are implementation of simple games that you can play in the console like a [Guess the Number](00-guess-the-number) game or a [Game of Life](02-ascii-game-of-life) simulation.

## Exercises

| Exercise | Name | Level |
| :---: | :---: | :---: |
| Exercise 00 | [Guess the Number](00-guess-the-number) | ⭐ |
| Exercise 01 | [Tic Tac Toe](01-tic-tac-toe) | ⭐⭐ |
| Exercise 02 | [ASCII Game of Life](02-ascii-game-of-life) | ⭐⭐⭐ |

## Help

1/ You will need to create some randomness in some exercises using `rand()` and `srand()` functions.

2/ Understand what the **runtime** is and how games works in general.

3/ Understand the rule of each games, those exercise are not very complex algorithmically.
